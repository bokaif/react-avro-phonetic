# Examples

```bash
npm install @bokaif/react-avro-phonetic
```

| File | What it shows |
|---|---|
| `01-BasicWrapper.tsx` | Minimal `<Avro>` wrapper on an input |
| `02-HeadlessHook.tsx` | Custom dropdown with `useAvro` |
| `03-CustomStyles.tsx` | Styling the default dropdown |
| `04-ParseAPI.tsx` | `parse()` without any UI |
| `05-Textarea.tsx` | `<Avro>` on a `<textarea>` |
| `06-WithForm.tsx` | Works inside a `<form>` with `FormData` |
| `07-ControlledInput.tsx` | Reading the value via `onChange` |
| `08-MultipleInputs.tsx` | Multiple inputs on the same page |
