# `@bokaif/react-avro-phonetic` Examples

This folder contains functional examples demonstrating the capabilities of the newly enhanced `react-avro-phonetic` library.

## Examples Provided

1. **`01-BasicWrapper.tsx`**  
   Demonstrates how to use the `<Avro>` component to wrap standard HTML `<input>` and `<textarea>` elements to enable phonetic suggestions automatically.

2. **`02-HeadlessHook.tsx`**  
   Demonstrates how to use the `useAvro` hook to build a completely custom phonetic input UI, giving you full control over how and where suggestions render.

3. **`03-CustomStyles.tsx`**  
   Shows how to pass styling props (`dropdownStyle`, `itemStyle`, `activeItemStyle`) to the `<Avro>` wrapper to make the floating suggestion dropdown match your app's theme.

## How to run them

You can copy and paste the contents of any of these files into a standard React application (e.g. Next.js, Create React App, Vite) to see the library in action! Ensure you have the library installed:

```bash
npm install @bokaif/react-avro-phonetic
```
