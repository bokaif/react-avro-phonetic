# Examples

Reference implementations for `@bokaif/react-avro-phonetic`.

- `01-BasicWrapper.tsx`: Basic usage of the `<Avro>` wrapper component.
- `02-HeadlessHook.tsx`: Custom dropdown implementation using the `useAvro` hook.
- `03-CustomStyles.tsx`: Styling the default wrapper dropdown.

To use these examples, copy them into your React project and ensure the package is installed:

```bash
npm install @bokaif/react-avro-phonetic
```
